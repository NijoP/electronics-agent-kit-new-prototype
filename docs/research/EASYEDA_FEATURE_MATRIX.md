# EasyEDA feature matrix

Every feature identified in the [EasyEDA ecosystem audit](EASYEDA_ECOSYSTEM_AUDIT.md), with its
classification for EAK (directive Part 2), the evidence path inside the EasyEDA repository and the
recommendation. The rows are taken verbatim from the per-repository tables of the audit (no new
findings are introduced here); paths are relative to the named repository at the commit listed in the
audit inventory.

Classifications: **applicable directly** (adopt the concept as-is, re-implemented natively),
**requires adaptation** (useful, must be adapted to EAK-IR, the command engine or Rust),
**requires native EAK implementation** (EAK needs the capability but must build it itself, because the
EasyEDA version depends on the EasyEDA runtime, is absent, or its licence forbids reuse),
**future capability** (beyond Phases 1-4), **not applicable**.

How this feeds the plan: the [implementation plan](../architecture/EDA_DESKTOP_IMPLEMENTATION_PLAN.md)
cites the rows it uses. A short list of the rows with the most influence on the plan is at the end.
