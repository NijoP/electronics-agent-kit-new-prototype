# Implementation map (shared ledger)

Directive §3, written from the code on `main` at `7447f44` plus the knowledge slice. Workers read
this instead of re-auditing; correct a row when you change its area. **Nothing here has been
compiled or run since Phase 1**: "exists" means source is present and was code-reviewed, not that it works.
Per-feature status stays in `STATUS.md`; history in `docs/development/PROGRESS.md`.

| Area | What is there (paths) | Gaps / caveats |
|---|---|---|
| **Architecture** | Cargo workspace, one direction of dependency: `eak-core` (IR, geometry, library, units, integrity, migrate) ← `eak-runtime` (`Engine::execute`, `command.rs` Command enum, delta, store, journal, process, tasks, SQLite `index.rs`) ← `eak-engineering` / `eak-validation` / `eak-manufacturing` / `eak-simulation` (read-only over `&Project`) ← `eak-intelligence` (providers, typed tools, `mental`, `domain`, `knowledge`) ← `eak-harness` (`eak` CLI, MCP stdio, app endpoint, `design.rs` flow). `eak-terminal` (PTY) has no design access. Frontend `apps/desktop` (Tauri 2 + React/TS) over `apps/desktop/src-tauri/src/{lib,ai,models,parts,terminal,workspace}.rs`. See `docs/ARCHITECTURE.md`, ADRs 0001–0024. | No compiler run since Phase 1: expect fallout at merge points (`src-tauri/src/lib.rs`, `workspace.rs`, `eak-terminal` `set_context`). |
| **Project state** | `eak-core/src/ir.rs` `Project{id, revision, requirements, library, schematic, pcb, constraints, manufacturing}`; `project.eak.json` + `journal.jsonl` (ADR-0001); every change is a typed `Command` (~55 variants incl. `Batch`) through `Engine::execute` with `expected_revision`, approval class, apply-on-clone, integrity check, section diff delta, atomic write, undo/redo as new revisions (ADR-0003), crash recovery (`store.rs`). Ids are prefixed random (ADR-0002); geometry integer nm (ADR-0005). | `Requirement` is only `{id, text}`: no structured requirements, per-domain constraints, or product profile in the IR (multi-domain worker owns this). No net-role field (power/ground recognised by name). |
| **Component model** | `eak-core/src/library.rs` `ComponentDef{id,name,category,refdes_prefix,manufacturer,mpn,distributor,datasheet,symbol,footprint,pin_map,ratings,model3d,provenance}`; `Rating{name,value,unit,source,verified}`; `Model3d{kind,color,external_ref}`; built-ins in `builtin.rs`; project-local library copy; commands `ImportLibraryComponent`, `UpsertComponentDefinition`, `SetComponentProperties`, `AssignComponentFootprint`. Desktop `shell/LibraryPanel.tsx`, `PartsPanel.tsx`. | Ratings are flat: no min/typ/max, no recommended-vs-abs-max, no test conditions, no package/revision scope, no extracted-vs-verified datasheet state. Supplier id (`distributor`) sits on the same struct as engineering identity. Lifecycle absent. `external_ref` is a string only. |
| **3D** | Rust: `eak-engineering/src/scene3d.rs` (board slab + bodies, unknown heights listed, not invented; used by MECH checks). TS: `apps/desktop/src/viewer3d/{scene.ts,Viewer3D.tsx}` + `workspaces/viewer3d.workspace.tsx`, three.js, orbit/presets/layer toggles, bodies from library body height with the 85 %-courtyard rule. | No STEP/IGES import, no model loading/caching, no per-footprint transform from model metadata, no zone fill or drill holes in the view, courtyard outline stands in for silkscreen. Never built. |
| **Manufacturing** | `eak-manufacturing`: `gerber.rs`, `drill.rs`, `bom.rs`, `stackup.rs`, `fabpack.rs`, `zip.rs`, `lib.rs::compile` (package stays DRAFT unless required gates pass, ADR-0021); `distributor.rs` (`DistributorProvider` over a `Fetch` trait, 12 s timeout, bounded body; blocked responses surfaced, never invented), `sourcing.rs` (offline-first `SourcingRecord`, raw-byte SHA-256, search-hit → datasheet-matched → verified), `fabricator.rs` (BOM/CPL/zip + 2-layer capability checks, unchecked = `not_checked`). Desktop `ManufacturingPanel.tsx`; IPC `parts_search`, `parts_import`, `fabricator_prepare`, `export_manufacturing`. | `provider.rs` adds `SupplierProvider` + `Resilient` (cache, rate limit, retry/backoff, stale fallback) but desktop `parts_*` does not use it yet; Distributor keyword search currently answers 403 (reported as `Blocked`). Never labelled "manufacturing-ready". |
| **Knowledge retrieval** | **New (code-reviewed only; also exact part lookup, rerank, fact labels, `eak-core::datasheet` types):** `eak-intelligence/src/knowledge.rs` (pure-Rust BM25, chunk provenance, advisory label), harness tools `knowledge_search/cite/import` (`eak-harness/src/knowledge.rs`), `docs/engineering/KNOWLEDGE_RETRIEVAL.md`. Older: `eak-intelligence/src/mental.rs` (DESK M1–M6, 12-step procedure, derating), `domain/` classifier, `eak-manufacturing::sourcing` datasheet hash evidence. | No PDF/table extraction, no MPN/Distributor exact lookup in the index, no rerank, no dense hook, no per-fact trust labels. |
| **UI** | `apps/desktop/src`: `App.tsx`, `Workspace.tsx` (EDA), `shell/` (activity bar, explorer, tabs, panels, `CommandPalette.tsx`, rules/export dialogs, `ProjectOverview.tsx`), `SchematicView.tsx`, `PcbView.tsx` (+`routeTool.ts`, `tools/pcb/*`, `tools/schematic/*`), `ProjectHome.tsx`, `viewer3d/`, `terminal/` (xterm, `TerminalWorkspace.tsx`), `ModelSettings.tsx`, `design/{tokens.css,ui.tsx}` + `docs/design-system.md`. | No always-open assistant sidebar (by design). Settings/secondary views and canvas-level interaction changes not redone in the redesign. Vitest tests written, never run. |
| **Validation** | `eak-validation`: `erc.rs` (ERC-001..016), `drc.rs` (DRC-001..020), `mech.rs` (MECH-001..003), `dfm.rs` (DFM-001..010), `holes.rs`, `sourcing.rs`, `gates.rs` (fail-closed PASS/FAIL/UNKNOWN/NOT_RUN, ADR-0021), `report.rs` (revision- and input-hash-bound, `not_implemented`, `limitations`). `eak-engineering`: `ipc.rs`, `calc.rs`, `power.rs`, `copper.rs`, `netlist.rs`. | IPC tables unverified against the standard (`VERIFIED_AGAINST_STANDARD=false`); no thermal, SI/PI, RF, EMC, creepage in DRC; ngspice (`eak-simulation`) is optional and not evidence. |
| **Runtime** | `eak-runtime/src/process.rs` (project-scoped supervisor: timeout, bounded capture, tree kill), `tasks.rs`, `index.rs`; desktop multi-project registry `src-tauri/src/workspace.rs`; terminal `eak-terminal/src/lib.rs` `Manager` (PTY sessions, spaces, tabs, scrollback, agents list `agents.rs`, status `proc_info.rs`, control API `api.rs`, `eak-term` bin); harness app endpoint `eak-harness/src/endpoint.rs` (loopback socket + token, `.harness.json` record; app is single writer, direct engine otherwise under project lock). | No Windows named pipes for the endpoint; no agent (Claude Code, OpenCode, Pi) trialled through the harness; terminal persistence limited to layout. |
| **Missing functionality** | Structured multi-domain requirements and product profile; component identity separated from supplier ids with datasheet-aware values; supplier provider trait with cache/retry/offline; datasheet table extraction and fact trust labels; real 3D model pipeline (STEP, cache, transforms); existing-project rework flow (`NEXT_ACTION.md` item 6); differential pairs / impedance control; schematic↔PCB reconciliation UI beyond `SyncSchematicToPcb` + sync report; a release built from this tree. | Every item above is unverified by a compiler. |
