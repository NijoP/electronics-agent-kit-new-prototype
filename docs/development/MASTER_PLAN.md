# Master plan

Goal: an engineering workstation — EDA workspace, Terminal workspace, engineering harness — over one
EAK-IR with independent validation (`docs/PRODUCT_VISION.md`). Stages and states: `ROADMAP.md`.

Phase 1 (this integration): realign the repository with that vision, merge the terminal engine,
harness and provider catalog into one branch, remove the assistant UI leftovers and stale docs,
and keep licence notices intact. Later phases: compile and run everything once the testing freeze
is lifted, trial real agents through the harness, add context wiring and approvals UI, then
requirements/selection and the closed loop.
