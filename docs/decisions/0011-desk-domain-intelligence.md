# ADR-0011 DESK domain intelligence in `eak-intelligence`

**Date:** 2026-11-14 · **Status:** accepted (product-owner directive 2026-11-13: outcome 3, "100 classes of domain intelligence … non negotiable")

## Decision
* The full DESK domain registry (`library/pcb_domains` of github.com/NijoP/DESK, MIT, Python, reference
  only) is embedded in `eak-intelligence` as data: `crates/eak-intelligence/data/desk_domains.json`,
  generated by `scripts/gen-desk-domains.sh` (jq, no Python) and parsed with `serde_json`. It holds
  **100 domain classes (DESK "archetypes") in 14 domains, plus 17 overlays**. Each class keeps its
  name, description, classification keywords/features, required component roles, critical
  constraints, verification requirements, standards, unsupported conditions, rule ids and DESK
  maturity label (87 DRAFT, 13 OFFLINE_TESTED at generation).
* `eak_intelligence::domain` re-implements DESK's deterministic classifier over the EAK-IR design
  (project name, requirements, placed component definitions, net labels). Same scoring thresholds
  and the same safety behaviour (mains/HV ambiguity forces REVIEW_REQUIRED; interface classes are
  demoted when a controller is named). No model call, no API key. Exposed as the read-only agent
  tool `classify_domain` and as the desktop IPC command `domain_classification`.
* **Maturity ceiling.** Guidance shown for a class is capped by its DESK label (`Maturity::ceiling`).
  Only `VERIFIED_AGAINST_SOURCE` and `LIVE_VERIFIED` may be shown as requirements; everything else
  is "review prompts (unverified)"; `BLOCKED` shows nothing. EAK adds no evidence of its own.
* The DESK *rule engine* is not ported. Results always carry `not_implemented` and `limitations`;
  a classification is a hypothesis and never a pass.

## Options considered
* Port DESK's regex extractor with the `regex` crate: rejected, no new dependency without approval;
  a small hand-written word matcher and unit scanner covers the same ground.
* Parse DESK's JSON files at runtime from a DESK checkout: rejected, EAK must work independently.
* Embed 100 hand-written Rust consts: rejected, a generated data file keeps the registry auditable
  against DESK and re-generatable.

## Consequences
* `desk_domains.json` is third-party reference data under DESK's MIT licence (owner's repository);
  attribution is in `LICENSING.md`. Regenerate with `scripts/gen-desk-domains.sh <DESK checkout>`.
* Classification is only as good as the design text: an empty design is UNCLASSIFIED by design.
